# delta-mdl-grn-transfer
Measures algorithmic common information (Δ_MDL) in the Cho et al. (2003) ERK/RKIP signaling pathway (BIOMD0000000647) via SVD and strict out-of-regime MDL transfer. Compares biological kinetics against 128 topology-preserving shuffled- and uniform-rate controls to test causal invariance.
